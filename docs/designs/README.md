# Design previews

These are proposals and sample-data prototypes, separate from the Swift app. Download/clone the repository and open a standalone HTML file in a browser; GitHub's source view does not run the preview.

- [Fresh directions: Velocity / Studio](new-directions.html) — latest visual proposal. See [color decisions and status](../UI_COLOR_DIRECTIONS.md).
- [Earlier UX wireframes](ux-wireframes.html) — Focused set / Compact table flow study. Its coral stripes and card-top borders were subsequently rejected; retained only as design history.

The corresponding `.fragment.html` files are editable sources. Standalone previews include their renderer and use local browser state. They do not call ExerciseDB, connect to Apple Health, or edit app data. Interface icon/helper resources may require internet. Review browser state is disposable.

Preview approval is distinct from implementation approval. The source app has not adopted either fresh visual direction yet.
